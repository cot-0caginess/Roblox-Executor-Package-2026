## FAQ

### What is the XCutors collection?

XCutors is a package that bundles several popular Roblox script execution tools into one convenient loader. It is designed to provide a unified interface for managing and running Lua scripts on the Roblox Windows client.

### Is it safe to use?

The tools are provided for educational and development purposes. Usage involves interacting with external software, which may trigger anticomponent warnings. Users should exercise caution and understand the risks associated with modifying game clients.

### How do I update the executors?

Updates for individual executors will be posted in the repository's releases section. You can download the new version and replace the corresponding files in your installation folder, or download the full package again.

### My anticomponent flags a file. What should I do?

Many security tools flag script injection utilities as potential threats. This is a common false positive. You may need to add an exclusion for the XCutors folder in your anticomponent software's settings.

### Can I use this on a Mac or Linux?

No, the XCutors collection and the included executors are specifically built for the Windows operating system only. They rely on Windows-specific APIs and the Roblox Windows client.

### Where can I get help if something isn't working?

Check the documentation included in the package first. You can also open an issue on the GitHub repository detailing the problem, the executor you are using, and any error messages you see.

### Are the scripts included in the collection?

The package includes a basic script editor but not a large library of scripts. Users are expected to provide their own Lua scripts. You can find scripts from various online communities.

### What is the password for the archive?

The archive password is provided in the 'README.md' file within the repository. It is included to prevent automated distribution and ensure users read the instructions.
